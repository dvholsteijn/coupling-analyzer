# Project Context

## Purpose

The goal of this tool is to aid developers or AI coding agents with refactoring monolithic applications to a more modular architecture by visualizing coupling and cohesion in an application codebase.

primarily focus on analysing java based application. 

The tool easily integrates with maven based project in the form of a maven plugin.
